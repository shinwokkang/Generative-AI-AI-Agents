# Lesson 1.5: 행동 - LLM과 도구 사용 (Action: Using Tools with LLMs) 🛠️

이 레슨에서는 AI 에이전트가 사전 학습된 지식을 넘어 외부 세계와 상호작용할 수 있도록 해주는 핵심 빌딩 블록인 **행동(Action)**과 **도구 사용(Tool Use)**에 대해 학습합니다.

---

## 1. 도구(Tools)와 행동(Actions)의 정의

* **도구 (Tools)**
  * AI 에이전트가 특정 태스크를 해결하기 위해 호출할 수 있는 **외부 함수, 웹 서비스, 또는 API**를 의미합니다.
  * LLM이 자체 파라미터에 저장된 고정된 지식을 초과하여, 실시간 데이터 원천이나 외부 시스템과 동적으로 연동할 수 있는 통로가 됩니다.
* **행동 (Actions)**
  * 에이전트의 추론과 판단에 따라 생성된 출력을 통해 실행되는 **모든 실제 작업(동작)**을 뜻합니다.

---

## 2. 행동(Actions)의 두 가지 주요 유형

에이전트가 외부 시스템과 맺는 상호작용 유형은 크게 두 가지로 분류됩니다.

| 행동 유형 | 설명 | 실제 예시 |
| :--- | :--- | :--- |
| **읽기 행동<br>(Read Actions)** | 외부 소스로부터 필요한 정보 및 데이터를 조회하고 획득하는 작업 | • 날씨 정보 API 조회<br>• 웹 검색 API로 최신 뉴스 검색<br>• 고객 DB에서 주문 내역 가져오기 |
| **쓰기 행동<br>(Write Actions)** | 외부 시스템의 상태를 변경하거나 데이터를 수정, 추가 및 동작을 유발하는 작업 | • 개인화된 이메일 발송<br>• DB에 새로운 레코드 삽입<br>• 일정 캘린더에 회의 등록 및 초대 발송<br>• 결제 서비스를 통한 금융 거래 승인 |

---

## 3. 함수 호출 (Function Calling)과 스키마

**함수 호출(Function Calling)**은 LLM이 구조화된 포맷(주로 JSON)을 출력하여 외부 API나 로컬 함수를 실행할 수 있도록 하는 메커니즘입니다.

* **구조화된 출력 (Structured Outputs):**
  * LLM이 무작위적인 자유 형식의 텍스트가 아닌, 사전에 약속된 **JSON 스키마(Schema)** 형식에 일치하도록 답변을 구성합니다.
* **신뢰성 보장:**
  * 규격화된 포맷으로 값을 반환하므로 백엔드 파서(Parser)가 이를 안정적으로 수집 및 파싱할 수 있어 에이전트 전체 시스템의 견고성과 신뢰성을 극대화합니다.

---

## 4. 도구 사용이 에이전트에게 중요한 이유

1. **지식의 한계 돌파:** LLM의 학습 컷오프(Knowledge Cutoff) 기간을 극복하고, 언제나 최신 정보에 접근합니다.
2. **역량의 무한 확장:** 단순 언어 생성기 수준을 넘어, 스케줄링, 연산, 파일 조작 등 물리적이고 자동화된 행동들을 수행할 수 있습니다.
3. **환경과의 실시간 피드백 루프:** 외부 시스템에 입력을 넣고, 그 결과를 다시 입력 컨텍스트로 수용하여 다음 판단의 정확도를 점진적으로 개선합니다.
